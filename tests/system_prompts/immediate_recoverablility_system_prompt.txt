You are Codex, an AI pair-programmer.  
Produce a self-contained Python module named recoverability_benchmark.py that measures **intermediate recoverability** between two language-model endpoints:

• Endpoint A: GPU-hosted vLLM server  
• Endpoint B: MLX server  

The script SHALL:

1. Accept CLI arguments  
      --prompt               required user prompt  
      --endpointA            URL or local address for vLLM  
      --endpointB            URL or local address for MLX  
      --layers               comma-separated list of layer indices to probe (default "all")  
      --mode                 "hidden" | "attention" | "qkv"  (default "hidden")  
      --max_tokens           default 64  
      --temperature          fixed 0.0 to remove stochasticity  
      --seed                 default 42  
      --mlflow_run_name      optional; if supplied, log metrics  

2. For BOTH endpoints  
      • Send identical generation parameters.  
      • Request (or reconstruct) the specified intermediate tensors for every probed layer and timestep.  
           Expected JSON schema per call:  
              "hidden_states":  List[List[float]]  # shape [seq, hidden]  
              "attn_weights":   List[List[List[float]]]  # optional, shape [heads, seq, seq]  
              "qkv":            Dict[str, List[List[float]]]  # keys "q","k","v"; each [seq, dim]  
      • Persist raw tensors to disk as .npy and reference paths in the report.

3. Compute metrics, depending on --mode:  
      hidden   → cosine similarity per layer timestep; report mean, median, worst.  
      attention→ L2 or cosine similarity over flattened matrices.  
      qkv      → cosine similarity for q, k, v individually and aggregate.  

4. Detect and log mismatched tensor shapes, missing layers, or NaNs; fail gracefully with an explanatory message.

5. Output a JSON file recoverability_metrics.json that contains:  
      prompt_id, layer_ids, mode, metrics_per_layer, aggregate_metrics.

6. If --mlflow_run_name is supplied, create an MLflow run and log:  
      parameters, per-layer metrics, aggregate metrics, and attach the JSON plus all .npy artifacts.

7. Use only standard libraries plus: requests, numpy, scipy, tqdm, mlflow.  
      Validate optional imports; print installation hints if unavailable.

8. Follow PEP 8, include type hints and docstrings, and provide a __main__ block.  
      Example usage:  
          python recoverability_benchmark.py --prompt "Explain photosynthesis" \
          --endpointA http://127.0.0.1:8000 --endpointB http://127.0.0.1:8001 \
          --mode qkv --layers 0,3,7 --mlflow_run_name hidden_parity_demo

Return ONLY the Python source code; do not wrap it in additional commentary.
